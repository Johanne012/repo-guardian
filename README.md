# Repo Guardian

نظام مراقبة ذاتي ذكي لمستودعات GitHub.

## المبادئ

- يراقب جميع المستودعات بشكل دوري
- يحلل الصحة (نشاط، Vercel، README، Issues، تسمية...)
- يقرر تلقائياً: إصلاح / اقتراح / أرشفة / تجاهل
- **يرسل بريداً فقط في الحالات الحرجة أو التي تحتاج تأكيداً بشرياً**

## مستويات الخطورة

| المستوى | الوصف | بريد؟ |
|---------|-------|-------|
| Info | تحديث عادي | لا |
| Warning | يحتاج انتباه خلال أسبوع | لا |
| Critical | مشكلة تؤثر على العمل | نعم |
| Confirm | قرار يحتاج موافقتك | نعم |

## الحالة الحالية

- تم إنشاء المستودع
- تم إنشاء Issues في المستودعات الحرجة
- الخطوة التالية: بناء منطق المراقبة
